Bab 2: Panduan Konfigurasi Klien-Server (LAN Multi-Komputer)

Menghubungkan banyak komputer perpustakaan ke satu database terpusat

Arsitektur Klien-Server memungkinkan komputer meja petugas dan komputer kios presensi pintu masuk terhubung ke SATU DATABASE SQLITE TERPUSAT secara Real-Time.

💻 1. Komputer Server Utama

Buka menu 🔐 Portal Admin (PIN: PustakaSmart2026) -> ⚙️ Pengaturan. Catat Alamat IP Server yang tertera pada kotak biru (Contoh: http://192.168.1.15:3001).

🖥️ 2. Komputer Client / Kios Presensi

Buka menu ⚙️ Pengaturan di Komputer Client -> masukkan URL Server IP (http://192.168.1.15:3001) -> klik Hubungkan. Status akan berubah menjadi 🟢 Terhubung Ke Backend Server SQLite.

⚠️ PENTING: Pastikan Komputer Server dan Komputer Client terhubung ke jaringan Wi-Fi atau kabel LAN sekolah yang sama.

Bab 5: Pengamanan Data SQLite & Backup Anti-Hilang

Penyimpanan file disk fisik & pemulihan backup offline

Seluruh data tersimpan permanen di file disk ./data/pustakasmart.sqlite. Untuk mengamankan data ekstra:

  1. Masuk ke menu 🔐 Portal Admin -> ⚙️ Pengaturan.
  2. Klik tombol Download Backup JSON Sekarang untuk mengunduh seluruh data ke file JSON.
  3. Simpan file cadangan tersebut di Flashdisk atau Google Drive Anda.
  4. Untuk memulihkan data, klik Pilih File Backup JSON dari Komputer... -> data akan pulih total dalam 2 detik!
